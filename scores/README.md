# 摇头曲谱

以后新增的摇头曲谱统一放在本目录。曲谱以 Markdown 编写，优先保证戴着眼镜排练时也能快速看懂。

## 统一记法

- `1 格 = 250 ms`：对应钢琴音色的最小触发网格。
- `↙ ↑ ↗` 等箭头：从中心摇向指定方向并触发音符。
- `·`：向中心方向回收至少 `2°`；不要求精确回到校准零点，也不是再次触发。
- `—`：留白，不做新的摇头动作。
- 普通音符默认占 `2 格`：第 1 格触发，第 2 格回中，共 `500 ms`。
- 延长音默认占 `4 格`：第 1 格触发，后 3 格回中或保持留白，共 `1000 ms`。

一次动作必须先回收至少 `2°`，再开始至少 `3°` 的新外摆。不要用一次持续向左或向右的运动代替多个音符。

## 音高与方向

曲谱采用便于记忆的两排六音布局：低音在下排，高音在上排。

| 简谱 | 音名 | 动作 | 建议相对姿态 |
|---:|:---:|:---:|:---|
| 1 | C4 | ↙ | 左下，大约 `yaw -27° / pitch -18°` |
| 2 | D4 | ↓ | 下方，大约 `yaw -9° / pitch -18°` |
| 3 | E4 | ↘ | 右下，大约 `yaw +27° / pitch -18°` |
| 4 | F4 | ↖ | 左上，大约 `yaw -27° / pitch +18°` |
| 5 | G4 | ↑ | 上方，大约 `yaw -9° / pitch +18°` |
| 6 | A4 | ↗ | 右上，大约 `yaw +27° / pitch +18°` |

角度只用于说明方向区域，不要求精确测量；超过 `3°` 即可触发。下一音只要求从本次动作峰值回收至少 `2°`，然后重新向外运动至少 `3°`；回到绝对中心只是更容易识别的快速路径。

## 文件命名

使用小写英文短横线命名：

```text
scores/
├── README.md
└── twinkle-twinkle-little-star.md
```

每份曲谱依次写明：适用音色、节拍、动作图例、速读版、逐句表格和练习建议。

> 当前摇摇乐的自由演奏模式会根据动作区域与实时和声生成音符，并不会强制命中曲谱指定音高。本目录先固定“目标旋律 + 节拍 + 动作”；后续接入曲谱演奏模式时，应以这里的音名为准，而不是依赖自由演奏的和声选音结果。
