# 《小星星》摇头曲谱

适用音色：钢琴  
调性：C 大调  
速度：舒适练习速度，每个普通音 `500 ms`  
钢琴网格：`250 ms/格`，普通音占 2 格，句尾延长音占 4 格

## 先记住六个动作

```text
低音：1(C) ↙    2(D) ↓    3(E) ↘
高音：4(F) ↖    5(G) ↑    6(A) ↗

· = 向中心回收至少 2°     — = 留白、不触发
```

每个普通音都按“摇出 → 回中”完成：

```text
↙· = 左下触发 C，然后向中心回收至少 2°，共 500 ms
↑··· = 上方触发 G，然后回收并留下 750 ms 空间，共 1000 ms
```

## 练习顺序

1. 先只练第 1–2 小节，每个箭头后明确回中。
2. 能稳定做到一次动作只响一个音，再练第 3–4 小节。
3. 最后连接全曲；句尾看到三个点时，不要抢着触发下一句。

如果连续出现两个相同音，例如开头的 `1 1`，仍然必须做两次完整动作：

```text
↙ → 回收至少 2° → ↙再外摆至少 3° → 回收
```

不必精确回到中心，但不能持续停在左下方等待第二个音；必须出现一次可识别的回程和一次新的外摆。
